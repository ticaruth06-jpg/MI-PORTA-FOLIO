# Portafolio Académico – Nayeli Quispe Tica (UPLA · U00057H)

## IMPORTANTE: los nombres de los archivos
En GitHub los archivos deben llamarse EXACTAMENTE así (sin "(1)"):
  index.html · style.css · script.js · logo-universidad.png · foto-estudiante.png · .nojekyll
Si en tu repositorio hay archivos como "style (1).css" o "script (1).js", la página sale sin diseño.
Bórralos desde GitHub (abrir el archivo → ícono de tres puntos → Delete file) y sube estos.

## Cómo reemplazar
Repositorio MI-PORTAFOLIO-ACADEMICO → Add file → Upload files → arrastra estos 6 archivos → Commit changes.
La carpeta "entregas" no se toca: todo lo que ya subiste sigue apareciendo.
Si existe entregas.json en la raíz, ya no se usa (puedes borrarlo).

## Carpetas de tareas
entregas/algoritmo/semana-01/...   entregas/taller/semana-01/...
Dentro: tus archivos, tema.txt (tema de la semana) y enlaces (enlaces.txt, un enlace por línea).

## Visor de imágenes
Botón "Ver" → la imagen se abre grande. Clic para acercar y otro clic para volver; rueda del mouse; arrastrar;
botones ➖ ➕ Normal; flechas para la siguiente imagen; pellizco con dos dedos en el celular.

## Acceso
- Cualquier persona que abra el enlace (el profesor) puede ver todo, ver las imágenes grandes y descargar. No necesita iniciar sesión.
- Iniciar sesión es solo para ti (clave 1234; se cambia en script.js → claveAdministrador). Al entrar ves en cada semana:
  subir archivos, añadir enlaces, cambiar el tema y 🗑 Descartar en cada archivo/enlace.
- Descartar abre GitHub en la página de borrado: pulsa "Commit changes" y vuelve; la lista se actualiza sola (o pulsa ↻ Actualizar lista).
